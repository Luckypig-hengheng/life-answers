ESP32-C3 SuperMini + 2.13" 墨水屏 + MPU-6500/9250 + 锂电池供电

① 墨水屏驱动板 v1.4 → ESP32-C3

驱动板丝印ESP32-C3功能
GND──→GND共地
3V3──→3V3驱动板供电
SCK──→GPIO4SPI 时钟
SDA──→GPIO6SPI MOSI
RST──→GPIO2复位（商家图: 2=RST）
DC──→GPIO3数据/命令（商家图: 3=DC）
CS1──→GPIO7片选（v1.2/v1.3 板上标 CS）
CS2──→不接单芯片屏无需接
BUSY──→GPIO10忙信号
DC / RST 千万别接反：接反时芯片被持续复位，表现为 BUSY 永久为低、刷新 10 秒超时、电流恒定 1.6mA、屏幕全白。
屏驱动芯片为 SSD1675B，固件用 GxEPD2_213_B72（商家示例 ink_test 指定）。24P 排线插入驱动板 FPC 座时对准 1 脚，绿色胶带面朝有元件一侧；排线只能水平弯折。

② MPU-6500 / 9250 → ESP32-C3

MPU 模块ESP32-C3功能
VCC──→3V3供电
GND──→GND共地
SDA──→GPIO8I2C 数据
SCL──→GPIO9I2C 时钟
INT──→GPIO0运动中断 → 深度睡眠唤醒
AD0──→悬空 / GNDI2C 地址 0x68
INT 必须接 GPIO0~5 范围内的引脚（ESP32-C3 只有这些支持深度睡眠 GPIO 唤醒），本方案固定用 GPIO0。

⚠ 注意：锂电池千万不要直接接 SuperMini 的 3V3 引脚（满电 4.2V 会超压）， 一定接 5V 引脚走板载 LDO。充电时可以边充边用；外壳内注意电池绝缘固定，避免排线被挤压。
